### 4.x Known constraint: `mode=both` (two makers in one cmsRun) is not supported

The two CVH makers cannot be scheduled in the same cmsRun process. Each maker is `edm::stream::EDProducer<edm::GlobalCache<CvhMasterThread>>`; each `CvhMasterThread` constructs its own `G4MTRunManagerKernel`, which trips Geant4's single-master singleton at the second `G4Region` constructor (confirmed by stack trace: `CvhMaster::CvhMaster() → G4MTRunManagerKernel::G4MTRunManagerKernel() → G4Region::G4Region() → SIGSEGV`). The driver's `mode` knob is therefore mandatory-pick-one — `dimuon` or `kaon` — and the splitter runs cheaply in both jobs. A `both` value is reserved for a future CvhMasterThread shared-singleton refactor; today it deliberately raises a clear failure mode rather than appearing to "work".
